# SPLAT Rig Runtime Editor — Work in Progress

Experimental runtime rig editing system for SPLAT.

## Status

**Work in Progress / Beta**

This system is under active development and is not part of the normal SPLAT release.

It is intentionally kept in the `experimental` area and should not be treated as production-ready.

## Current components

- CET runtime profile/editor
- REDscript native bridge
- Native RED4ext runtime plugin
- Live rig adjustment support

## Important

Do not include this experimental system in normal SPLAT release packages until it has been fully tested and approved for integration.
